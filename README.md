# Реч БГ

Българско SaaS аудио студио, готово за конфигуриране и публикуване чрез **Cloudflare Workers Builds + GitHub**.

## Какво има

- Изцяло български маркетинг сайт: начало, цени, 30 гласа, за нас, контакт, общи условия, поверителност, бисквитки, отказ и възстановяване.
- Регистрация, потвърждение на имейл, вход, забравена парола, смяна на парола, частни сесии, експорт и изтриване на профил.
- Табло, проекти, студио за текст в реч, двугласен подкаст и озвучаване. TXT импорт, сценарии, избор на гласове, паузи, история на записите и WAV изтегляне.
- Генериране чрез Cloudflare AI binding, устойчиви фонови Workflows, частно R2 съхранение, D1 база. Същият плосък TTS договор и WAV/PCM нормализация като в `notebook`.
- Реални Stripe Checkout/Customer Portal интеграции и подписани webhooks. Атомарни квоти, повторяеми заявки без двойно начисляване, възстановяване при провал.
- Административен екран в Настройки за качване на истински аудио примери и преглед на контактни запитвания.
- Изчистен интерфейс с плътни цветове, собствена типография и графика на звукова вълна. Без градиенти, измислени отзиви или публични имена на модели.

## Пускане

Прочетете **[docs/DEPLOYMENT.md](docs/DEPLOYMENT.md)**. Не е необходима външна SQL услуга — приложението е изградено за Cloudflare D1.

| План | Цена / месец | Символи |
| --- | ---: | ---: |
| Проба | €0 | 1 000 еднократно след потвърждение на имейл |
| Начало | €9 | 30 000 |
| Създател | €19 | 100 000 |
| Студио | €39 | 250 000 |

Всички гласове и формати са достъпни във всички планове в рамките на наличната квота. До 10 000 озвучавани символа и 40 части на запис; до 100 проекта на профил. Неизползваните месечни символи не се прехвърлят. Цените са с включени приложими данъци; Stripe цените трябва да са `tax_behavior=inclusive`.

Това са начални продуктови цени, а не твърдение за гарантиран марж. Измерете действителните разходи върху български записи, преди да ги рекламирате широко — вижте [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Локална разработка

Node.js 24 и npm:

```sh
npm ci
cp .dev.vars.example .dev.vars
npm run db:local
npm run preview
```

`preview` компилира клиента и стартира Worker с локални D1/R2 ресурси на порт 8787. За работа с HMR оставете Worker да работи и в друг терминал изпълнете `npm run dev`. При тази комбинация задайте `SITE_URL=http://localhost:5173` в `.dev.vars`, за да съвпада проверката на Origin с Vite.

Локалният режим няма фалшив аудио генератор. За реално аудио е нужен достъп до Workers AI. Публичните страници работят преди активиране на регистрации; имейлите и плащанията изискват конфигурация.

```sh
npm run build
npm test
npx wrangler deploy --dry-run --no-autoconfig
```

Тестовете изпълняват реалните Hono маршрути, SQL схема/тригери и Workflow логика с локални SQLite, R2 и AI тестови адаптери. Stripe подписите са реално генерирани и проверени; външните Stripe HTTP отговори са симулирани. Те не заместват проверка в реалния Cloudflare/Stripe акаунт.

## Известни граници при предаване

- Няма включени живи ключове, база, Stripe продукти или аудио примери.
- Реалната AI генерация, изпращане на писмо, плащане и webhook доставка предстои да се проверят след конфигурация.
- Локалният браузърен преглед беше блокиран от средата за изпълнение; визуална проверка на десктоп и телефон е част от приемането на реалния deployment.
- Подкастът използва **въведен от потребителя сценарий** с двама водещи. Не обещава автоматично писане на сценарии от тема, voice cloning, MP3 експорт или музикален монтаж.
- Форматът за озвучаване създава WAV файл за добавяне във външен видео редактор; не рендерира видео.
